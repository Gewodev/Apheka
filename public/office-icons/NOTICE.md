# Microsoft Fluent UI file type icons

Original DOCX, XLSX and PPTX file type SVG assets distributed by Microsoft Fluent UI. Downloaded on 2026-10-30 and bundled locally to avoid runtime CDN requests.

- Documentation: https://github.com/microsoft/fluentui/blob/master/packages/react-file-type-icons/README.md
- Source base: https://res.cdn.office.net/files/fabric-cdn-prod_20260113.001/assets/item-types/48/
- Files: docx.svg, xlsx.svg, pptx.svg

Microsoft, Word, Excel and PowerPoint names and marks belong to Microsoft. These assets identify file formats; APHEKA is an independent application.

Additional original Microsoft Fluent file-type assets: pdf.svg, txt.svg, code.svg, photo.svg from the same documented CDN path. They represent file types, not an endorsement by the format owner.
